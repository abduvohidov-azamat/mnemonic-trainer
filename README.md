# Mnemonic Memory Training Platform

A high-performance memory sports training platform built with **Angular 18+ (Standalone & Signals)** and **Nest.js 10+ (SQLite & TypeORM)**.

## Key Disciplines & Features
- **Speed Numbers**: 20-500 digits with customizable locus chunking (1, 2, or 3 digits), auto-pacer, and color-coded accuracy diffing.
- **Speed Cards**: 52-card deck & custom subsets, flip transitions, and an interactive 52-card selector recall matrix.
- **Random Words / Names**: 10-50 words sequence with Levenshtein-distance fuzzy typo tolerance.
- **PAO (Person-Action-Object) Matrix**: 00-99 & 52 Playing Cards complete Major System dictionary with live in-session hints and customization.
- **Session Telemetry & Analytics**: Accurate millisecond timing, digits-per-minute scoring, and progress history.

## Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm 9+

### Installation & Run
```bash
# Install dependencies in backend and frontend
npm run dev:all
```
- Frontend: `http://localhost:4200`
- Backend API: `http://localhost:3000/api`
